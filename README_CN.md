# xiaomi-bootlogo-editor

[English](README.md)

高通平台小米/红米手机开机logo解包打包工具

## 兼容性

仅支持高通平台
从MIUI13开始，开机logo已移至 `imagefv` 分区，此工具不再支持

首先你需要确定你的机器受支持，你只需要备份 `logo` 分区并尝试解包
如果成功解包，那么你的机器就受支持

备注: 如果 `logo` 分区解包失败, 你还可以试试 `splash` 分区

已知支持的设备:
- 小米6 (sagit)
- 小米8 (dipper)
- 小米9 (cepheus)
- 红米K20Pro (raphael)
- 小米MIX 2S (polaris)

## 重要信息

此工具给所有解包后的文件都加上BMP后缀，但不一定全部图片都是BMP格式
例如小米8(dipper)就有一张图片(第三张)是png格式
修改完这些不同格式的图片后，一定要保证文件名仍是 `logoX.bmp`

你需要搞清楚每一张图片的格式，可以用winhex或者线上工具查看
如果你不知道怎么做，可以查看文件大小，其他格式图片显著小于同分辨率BMP文件

你需要用格式相同的图片替换解包后的图片文件
但是你可以尝试使用不同的分辨率，特别是小米8这种logo分辨率奇奇怪怪的
但是别超过你屏幕的分辨率，也要确保打包后的文件不大于logo分区大小

## 解包

0. 一定要在再次解包前删除 `unpacked` 文件夹
1. 备份你的 `logo` 分区，放在工具目录下
2. 打开命令行(Windows:CMD Linux:终端)输入 `logotool unpack <你备份的文件名>`
3. 解包后的文件在 `unpacked` 文件夹

## 重新打包

0. 一定要确定 `unpacked` 文件夹和里面的 `logoX.bmp` 存在
1. 打开命令行输入 `logotool repack <你的新logo镜像文件名>`
2. 确认新的镜像不超过 `logo` 分区大小
3. 刷入你的新镜像
